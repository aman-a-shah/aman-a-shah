## 🚀 What I’m Building

### 🎙️ [Speech2Text – AI Speech Transcriber](https://github.com/aman-a-shah/speech2text)
*Python, Faster-Whisper, sounddevice, AppleScript*

A lightweight, privacy-focused macOS app that transcribes speech locally using OpenAI’s Whisper models.  
- ⚡ **Real-time capture** with global hotkey (Cmd+Shift+Space)  
- 🔒 **100% on-device** – no cloud, no latency, no privacy trade-offs  
- 🧠 **Multi-threaded** with VAD filtering and lazy model loading  
- ⌨️ **Auto-paste** at cursor with clipboard preservation
